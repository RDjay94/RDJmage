# Henry's Gaming Mouse — iPhone as a mouse for Mac (BLE)

Two Swift apps that pair over a custom Bluetooth Low Energy GATT service:

- **Henry's Gaming Mouse** (iOS, SwiftUI) — the trackpad UI plus motion control. Advertises as a BLE peripheral.
- **Henry's Gaming Mouse Host** (macOS, SwiftUI, menu bar) — connects to the iPhone, decodes input packets, and synthesizes cursor events with `CGEvent`.

## Why a custom GATT service (not "real" BLE HID)

iOS does **not** allow third-party apps to advertise the standard Bluetooth HID profile (service UUID `0x1812` is reserved by Apple). A normal App Store app cannot impersonate a generic Bluetooth mouse to *any* Mac without MFi entitlements. The standard, App-Store-friendly workaround — used by Remote Mouse, Mobile Mouse, etc. — is to expose a **custom GATT service** that a companion Mac app reads, then translate the packets to OS cursor events. That's what this project does.

## Build (Xcode 15+)

These source files don't include `.xcodeproj` packages (they're best generated by Xcode itself so they pick up your team ID). Set up each target once, drag the sources in, and you're done.

### iOS app

1. Xcode → New → Project → **iOS** → **App**. Product name `HenrysGamingMouse`, Interface **SwiftUI**, Language **Swift**.
2. Delete the default `ContentView.swift` and the `@main` app file Xcode generates.
3. Drag `henrys-gaming-mouse/iOS/HenrysGamingMouse/*.swift` and `henrys-gaming-mouse/Shared/BLEProtocol.swift` into the target. Check "Copy items if needed".
4. Replace the auto-generated `Info.plist` with `henrys-gaming-mouse/iOS/HenrysGamingMouse/Info.plist`, or open the target's *Info* tab and add these keys:
   - `NSBluetoothAlwaysUsageDescription`
   - `NSBluetoothPeripheralUsageDescription`
   - `NSMotionUsageDescription`
   - `UIBackgroundModes` → `bluetooth-peripheral`
5. Signing & Capabilities → enable **Background Modes** → check *Uses Bluetooth LE accessories* and *Acts as Bluetooth LE accessory*.
6. Set the display name on the target's General tab to `Henry's Gaming Mouse`.
7. Deployment target iOS 16+. Run on a physical device — BLE peripheral mode does not work in the simulator.

### macOS host

1. Xcode → New → Project → **macOS** → **App**. Product name `HenrysGamingMouseHost`, Interface **SwiftUI**.
2. Drag `henrys-gaming-mouse/macOS/HenrysGamingMouseHost/*.swift` and `henrys-gaming-mouse/Shared/BLEProtocol.swift` into the target.
3. Replace the generated `Info.plist` with `henrys-gaming-mouse/macOS/HenrysGamingMouseHost/Info.plist` (it sets `LSUIElement` so the app is menu-bar only).
4. Set the entitlements file to `HenrysGamingMouseHost.entitlements`. **Turn the App Sandbox off** — sandboxed apps cannot post `CGEvent`s to the system event tap.
5. Build & run. After first launch:
   - Grant **Bluetooth** when prompted.
   - System Settings → **Privacy & Security → Accessibility** → enable Henry's Gaming Mouse Host. *Without this, cursor events are silently dropped.*

### Pairing

1. Launch the Mac app — it starts scanning automatically.
2. Open Henry's Gaming Mouse on the iPhone — it starts advertising.
3. The Mac picks it up, connects, and the menu-bar icon turns into a cursor with motion lines.
4. Drag on the iPhone trackpad → cursor moves on the Mac. Flip the **Tilt** toggle to add motion control.

## App Store notes

- The iOS app is plain CoreBluetooth + CoreMotion + SwiftUI — no special entitlements, no MFi program needed.
- Privacy strings (`NSBluetoothAlwaysUsageDescription`, `NSMotionUsageDescription`) are required by App Review.
- Make clear in the App Store description that the free Mac companion app is needed; submit the Mac app separately (it cannot be sandboxed, so distribute outside the Mac App Store as a notarized Developer ID DMG).

## Tuning

- Trackpad speed: `moveScale` in `TrackpadView.swift` (default 1.4 — close to native trackpad feel).
- Tilt speed: `sensitivity` in `MotionManager.swift`.
- Scroll: `scrollScale` in `TrackpadView.swift`.
- Two-finger scroll is currently approximate; for production, wrap a `UIPanGestureRecognizer` with `minimumNumberOfTouches = 2` via `UIViewRepresentable`.
