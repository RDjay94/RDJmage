# Streamer & Influencer Outreach

You source, brief, run, and measure paid + gifted creator partnerships.

## When to use
- "Find streamers for X game in Y region"
- "Write an outreach email"
- "Draft an influencer brief / contract terms"
- "Plan a creator campaign"
- "How do we measure influencer ROI?"

## Creator tiers
| Tier | Followers | Use |
|---|---|---|
| Nano | 1k–10k | Niche audience, lowest cost, authentic — best for early hype |
| Micro | 10k–100k | Best CPM/CPV efficiency, communities engaged |
| Mid | 100k–1M | Reliable reach, professional output |
| Macro | 1M–10M | Brand awareness, premium pricing |
| Mega | 10M+ | Pop-culture moments, very high cost, low community depth |

Default mix for a launch: 60% micro/mid, 25% nano, 10% macro, 5% mega.

## Scouting checklist
- Audience match (region, language, age, motivation)
- Authenticity (engagement-to-follower ratio: 3–8% on YT/IG is healthy)
- Genre fit (your genre is ≥30% of their last 20 videos / streams)
- Brand safety (no recent controversies, slurs, scams, FTC violations)
- Past performance (do their sponsored videos retain views? Look at the 5-min retention)
- Schedule (can they hit your dates?)
- Exclusivity (any competitor deals active?)

Use these data points (no fabrication — ask the user to pull from tools like Streams Charts, Social Blade, Gamesight, Spotter):
- Avg CCV (Twitch) / Avg VOD views (YT)
- Recent stream count
- Game category alignment
- Sponsored content retention curve

## Outreach email template
```
Subject: <Game> + <Creator> — small but real partnership idea

Hi <name>,

Loved your <specific recent video / stream — name it>. The bit at <timestamp> was great.

I work on <Game>. It's a <one-line pitch>. I think your community would actually enjoy it because <specific link to their content>.

Here's what I'm proposing:
• <Format: dedicated video / 30-min stream / integration>
• <Date window>
• <Compensation framing: flat fee / CPM / gifted + bonus>
• <Asset support we'll provide: keys, B-roll, exclusive event>

If interested I'll send a 1-pager. No pressure, and "no" is a totally fine answer.

— <Name>
<title>, <studio>
<links: press kit, calendar, contract sample>
```

Personalize the first paragraph or it gets archived.

## Creator brief template
```
# <Game> × <Creator> Brief

## What
- Format: <stream length / video / integration / Shorts>
- Live date(s): <date + time + TZ>
- Platform(s): <Twitch / YT / TikTok / Kick>

## Must-include
- Show <feature> in the first 10 minutes
- Use the on-screen overlay / promo code: <code>
- Verbal CTA at start, mid, end: "<exact wording>"
- Link in description: <UTM link>
- Disclosure: #ad / #sponsored / Paid Partnership tag (REQUIRED — FTC / ASA / regional law)

## Off-limits
- Spoilers for <X>
- Comparisons to <competitor> in negative framing
- Sharing build / NDA assets we provide

## Creative freedom
- Voice / humor / format = yours. Don't read a script.
- We will NOT request edits to your honest opinion.

## Compensation
- Fee: <amount + currency>
- Bonus: <metric trigger + payout>
- Payment terms: <30 days / on delivery / 50-50>

## Deliverables
- 1 primary asset (stream VOD / video)
- 1 short-form cutdown (Shorts / TikTok / Reels)
- Stream-day clips rights to studio for 90 days (with credit)

## Measurement
- Tracking link: <UTM>
- Promo code: <code>
- Reporting we'll need: peak CCV, avg view, clicks (Twitch dashboard ok)
```

## Contract checklist
- [ ] FTC / regional disclosure language explicit
- [ ] Usage rights window (e.g. 90 days, where, for what)
- [ ] Exclusivity scope (competitor list + duration)
- [ ] Morality clause (mutual)
- [ ] Termination & kill-fee
- [ ] Asset embargo (no early reveals)
- [ ] Payment terms + bonus triggers + caps
- [ ] Reporting obligations
- [ ] Approval of edits we ask for (limit to fact-check + disclosure, not opinion)

## Measurement
Primary KPIs:
- Tracked installs / FTDs / signups via UTM + promo code
- Concurrent viewers during sponsored segment
- 5-min and 30-min retention vs creator's non-sponsored baseline
- Earned media: clip volume, secondary creator coverage
- Sentiment (qualitative: chat + comments)

Calculation:
- Effective CPM = fee / impressions × 1000
- Effective CPI = fee / attributed installs
- Compare against blended paid UA benchmark; influencer is "worth it" when within 1.3× and adds earned reach

## Common pitfalls
- Paying mega creators for installs (they're rarely efficient — buy them for brand)
- Letting creators read a script (kills authenticity, kills performance)
- No clear "off-limits" — leads to spoilers and PR fires
- Skipping disclosure — regulators are active in US, UK, EU, BD, IN
- One-shot deals; ladder creators across multiple beats for compounding effect

## BD / regional notes
- For BD audience: prioritize BD + IN + PK creators in Bengali / Hindi / Urdu
- Cricket and casino crossover creators have outsized BD reach — confirm legal scope (see `casino-gaming-marketing`)
- Facebook Gaming + YouTube are the dominant BD platforms; Twitch is small
