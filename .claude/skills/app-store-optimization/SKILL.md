# App Store Optimization (ASO)

You optimize store listings on the Apple App Store and Google Play so games convert better at every step from impression to install.

## When to use
- "Optimize our Play Store / App Store listing"
- "Keyword research for X game"
- "Write title/subtitle/description"
- "What screenshots should we show?"
- "Plan a store A/B test"

## Listing field cheat sheet
### Apple App Store
| Field | Limit | Purpose |
|---|---|---|
| App name | 30 chars | Keyword + brand |
| Subtitle | 30 chars | Indexed for keywords, plays to converters |
| Promotional text | 170 chars | NOT indexed, editable anytime |
| Keywords | 100 chars (comma-sep) | Hidden field, biggest lever |
| Description | 4000 chars | Conversion / re-engage page |
| Screenshots | up to 10 | First 3 are 80% of conversion |
| Preview video | 30s | Auto-plays, muted by default |
| In-app events | 30 char title | Indexed, big launch lever |
| CPPs | up to 35 | Per-keyword landing pages |

### Google Play
| Field | Limit | Purpose |
|---|---|---|
| App name | 30 chars | Heavy keyword weight |
| Short description | 80 chars | Indexed; appears above the fold |
| Long description | 4000 chars | Indexed (top + bottom weighted) |
| Screenshots | up to 8 | Above-fold conversion |
| Feature graphic | 1024x500 | Top of page |
| Promo video | youtube link | Auto-plays on some surfaces |
| Custom store listings | by region/lang/install state | Targeted variants |
| Store listing experiments | Built-in A/B testing | Use it constantly |

## Keyword research process
1. Seed list: genre nouns + verbs + brand + competitor brands + features
2. Expand with: AppTweak / Sensor Tower / data.ai / AppFollow OR Apple's own Search Ads keyword tool (free, accurate)
3. Score each on:
   - Volume / popularity
   - Chance (competition × your domain rating)
   - Relevance (keyword → install probability)
4. Group into themes per CPP
5. Localize: don't translate; research natively per market

## Title & subtitle frameworks

Apple App Store (60 chars total across name + subtitle):
- Brand : feature keywords
- e.g. `Empire Legends: Idle RPG Saga`
- e.g. `Pocket Fútbol: Real Soccer Cup`

Google Play (30-char name + 80-char short desc):
- Name = brand + 1 keyword
- Short desc = strongest hook + 2 keywords
- e.g. `Cricket Champs — Realistic 3D` / `Live BPL & IPL matches. Free-to-play cricket with real squads, real stars.`

## Description copy structure
Top 3 lines (above the fold) carry conversion. Bottom carries keywords.

```

<2nd line — 1–2 standout features>
```

## Screenshot brief
Order:
1. **Wow moment** — your most cinematic frame + 4-word headline
2. **Core loop visualized** — single panel, headline like "Build → Battle → Brag"
3. **Feature stack** — 3 small features in one frame
4. **Social proof** — review stars / award / "10M players"
5. **Live-ops / event** — current limited content
6. **PvP / multiplayer** if applicable
7. **Customization / depth** — collection, characters
8. **CTA frame** — "Play free now"

Design rules:
- Headline text > game visual; viewers don't recognize random gameplay
- High contrast, big type, mobile-thumb-readable
- Aspect ratios: portrait 1284×2778 (iPhone 6.7"), landscape variant if PvP-heavy
- Burn captions in localized fonts; never auto-translate

## Preview / feature video (30s)
- 0–3s: Strongest hook frame, sound on
- 3–18s: 4–5 short cuts of feature variety
- 18–25s: Build-up / progression / payoff
- 25–30s: Logo + "Play free" end card
- Provide a no-text version for global use

## Localization (default markets)
Top priority for BD / South Asia title:
- Bengali (BD + IN-West Bengal)
- Hindi (IN)
- English (worldwide)
- Indonesian, Spanish, Portuguese-BR, Russian, German, French, Japanese, Korean, Simplified Chinese (priority order varies by genre)

Per market deliver: title, subtitle, keywords (Apple), short desc (Google), 4000-char long desc, screenshots with native-language burn-ins, native preview video.

## A/B testing
Google Play has Store Listing Experiments (use it). Apple has Product Page Optimization (PPO).
- Test ONE element per experiment (icon OR first screenshot OR subtitle)
- Min 50k visitors per arm before declaring; 95% confidence
- Run 7 days minimum to capture weekday/weekend
- Document hypothesis → result → next test

Highest-impact tests in order:
1. App icon (10–25% install lift not unusual)
2. First screenshot
3. Subtitle / short description
4. Preview video first frame
5. Feature graphic (Google)

## Ratings & reviews
- Trigger in-app rating prompt at a moment of joy (after a big win, not after a defeat)
- Reply to ALL 1–3 star reviews within 7 days
- Reply briefly to 4–5 star reviews with thanks (boosts return rate)
- Address bugs in promo text + "What's New" — converts angry browsers

## Featuring strategy
- Apple Editorial: pitch via Apple Pitches Form, lead with craft + cultural fit + accessibility
- Google Play Editorial: feature graphic + landscape video; ship updates regularly
- Editorial loves: indie polish, localization, accessibility features, social impact, technical novelty

## BD / regional notes
- BD often defaults to lite installs on low-storage devices — keep app under 100MB or use Play Asset Delivery
- Bengali store visuals see ~30% better CTR vs English-only on the same audience
- Voice + cricket-themed games over-index in BD/IN

## Don'ts
- No keyword stuffing in title (Apple will reject)
- No fake reviews (Apple/Google permabans accounts)
- No screenshots with competitor logos
- No promises in copy you can't deliver ("Win real money" if you're not licensed)
- No misleading age rating
